# Prototipo v0

`index.html` es la primera versión del tablero: un único archivo con D3, Three.js y todos los datos incrustados, construido en octubre de 2026 con la ayuda de Claude (Anthropic) para explorar qué mostrar y cómo.

Sirvió para validar las secciones, los indicadores, la interacción del mapa, el catastro 3D y el modo reto. Sus datos quedaron congelados al 22 de octubre de 2026 y el analista con IA solo funciona dentro de Claude.

La versión que se está construyendo separa el pipeline de datos (`../pipeline`) de la aplicación web (`../web`) para que los datos se actualicen solos cada día. Ver [`../docs/ROADMAP.md`](../docs/ROADMAP.md).
